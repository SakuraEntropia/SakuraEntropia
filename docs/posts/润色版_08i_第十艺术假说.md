# 第十艺术假说

> 首发日期：2026-08-29

> 润色说明：仅调整语言衔接和段落排版，观点与论证按原稿保留。

电影曾经从戏剧中分离，证明了摄影机可以成为独立的艺术语言；动画曾经从绘画中分离，证明运动本身可以成为独立的艺术语言。而未来，游戏中的写实图形学也可能与游戏性逐渐分离。

当实时渲染不再以"服务游戏性"为主要目的，而开始探索自身的问题——光、材质、空间、运动、尺度、物理、生成、交互与计算——一种新的艺术形式可能由此诞生。它不再只是更逼真的游戏，也不只是没有游戏性的游戏，而是实时计算机图形本身成为艺术媒介。

它的作品可能没有传统意义上的"关卡"，也未必需要胜负、任务或叙事。它可能以一个持续计算的世界、一套视觉规律、一种空间体验，甚至一个不可重复的实时过程作为作品。

因此，**写实图形学 → 与游戏性分家 → 新艺术形式**，可以暂时称为"第十艺术"。至于它最终叫什么，现在反而不应该急着定义。因为电影诞生之前，没有人能够准确预言"电影语言"最终会是什么；动画也不是从一开始就知道自己会成为动画。名字应该由它自己的艺术语言诞生之后，再回头定义。

所以"第十艺术"不是一个最终名称，它更像一个占位符：**一种尚未获得正式名称的、以实时计算机图形为本体的艺术。**

## 待作者核查

- 「第十艺术」的编号隐含"游戏即第九艺术"这一前提；"第九艺术"的归属在不同地区有不同说法（漫画、电视、游戏等），建议发布前说明这一假设。
- 「电影曾经从戏剧中分离」「动画曾经从绘画中分离」为简化史观，属于论证前提而非严格史实，如需发布建议自查表述。

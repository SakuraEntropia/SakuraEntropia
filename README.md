## 🔭 What I'm working on

### 🎧 [Entropia-Atmos](https://github.com/SakuraEntropia/Entropia-Atmos) — *"Blender for spatial audio"*
An AI + graphics inspired **spatial audio engine** that borrows the modern rendering pipeline
(represent → simulate → shade → render → deliver) and points it at acoustics:
**AudioGS** (Audio Gaussian Splatting) sound fields, **Audio-USD** scene representation,
geometric **acoustic simulation** (image-source / ray tracing), **Acoustic-BRDF** material shading,
**HRTF binaural rendering**, and a **DSP graph**.
Ships offline **and** real-time renderers, a creator application, and plugin tooling. `TypeScript`

### 🧠 [Entropia-Riko](https://github.com/SakuraEntropia/Entropia-Riko) — node-graph deep-learning editor
**ComfyUI-style visual workflows for PyTorch** (with optional TensorFlow/Keras and Hugging Face nodes):
~200 built-in nodes, a Blender-like modular workspace, live training curves, subgraphs,
**code export**, a plugin system, and a built-in file manager.
Runs in the browser and as a standalone **Electron** desktop app; the Python runtime is on PyPI
as [`entropia-riko`](https://pypi.org/project/entropia-riko/). `Python` · `FastAPI` · `React`

### 🧩 [Entropia-Template-UI](https://github.com/SakuraEntropia/Entropia-Template-UI) — the shared UI shell
The reusable **node-graph editor front-end** extracted from Riko: React + Vite + TypeScript +
React Flow + Zustand, with Blender-style splittable panels, floating windows, themes
(incl. Apple Liquid Glass), code editor, and file picker — ready to wire to any backend.
Published on npm as [`entropia-template-ui`](https://www.npmjs.com/package/entropia-template-ui). `TypeScript`

### 📐 [Erdos-test](https://github.com/SakuraEntropia/Erdos-test) — formalising the Erdős–Straus conjecture
A **`sorry`-free Lean 4 + Mathlib** formalisation of the elementary layer around
`4/n = 1/x + 1/y + 1/z`: reduction to primes, the divisor–certificate bijection, parity structure,
a complete `a = 3` characterisation, Obláth's identity, and a one-sided divisor criterion.
Every claim carries a register tag — **A** proven, **B** computational, **C** conjecture,
**D** AI-generated — and they are never mixed.
> To be explicit: the conjecture is **not** solved here, and nothing in the repo claims it is. `Lean`

### ♾️ [Googology-Lean](https://github.com/SakuraEntropia/Googology-Lean)
A Lean definition of **Graham's number**. `Lean`
